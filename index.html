❯ omarchy · hermes desktop plugin

Omarchy-Themes, Hermes-nativ.

Ein omarchy-Theme-Set — und Desktop-Picker, ⌘K und CLI/TUI-Skin wechseln synchron. Ein Plugin, drei Komponenten, eine Wahrheit pro Klick.

Bidirektionaler Sync. Eine Wahrheit pro Klick.

omarchy theme set schreibt über den Hook ins Hermes-Skin-File. Der Hermes-Picker ruft denselben skin use-Pfad zurück. Pro Aktion gewinnt genau eine Seite.

  1. [1] Omarchy CLI

    omarchy theme set nord

    Source-of-Truth für Theme-Colors via colors.toml (User > System > current).

  2. [2] omarchy-themes

    hermes skin use nord

    Hook schreibt ~/.hermes/skins/nord.yaml (22 Keys, hex 3- oder 6-stellig), Plugin registriert die Palette im Picker und ⌘K.

  3. [3] Hermes UI

    applyTheme('nord')

    Desktop, CLI, TUI — alles in einem Schritt umgefärbt (light/dark + Accent via Rec.709-Luma-Synth).

Drei Komponenten, ein Theme-Flow.

Desktop-Plugin registriert die Paletten. Hook synct sie ins Hermes-Skin-File. Generator frischt sie nach jedem Omarchy-Update auf.

Keine der drei Komponenten ist optional — wer nur den Desktop-Picker will, kommt mit Plugin + Generator aus; wer auch CLI/TUI mitsyncen will, ergänzt den Hook.

plugin settings · ⌘K

Desktop plugin

Registriert jede Omarchy-Palette im Hermes-Picker, als ⌘K-Befehl (Apply Omarchy Theme: <Name>) und auf einer Settings-Karte mit Swatches, Filter und Apply. Jedes Theme bringt Light- und Dark-Palette mit; Brand-Accent wird geteilt, die Gegenpalette wird synthetisiert.

hermes plugins install https://github.com/cabroe/omarchy-themes
hook theme-set.d

Omarchy theme-set hook

Läuft bei jedem omarchy theme set <slug>. Parst die colors.toml (User > System > current), schreibt ~/.hermes/skins/<slug>.yaml und aktiviert den Skin via hermes skin use. Reines POSIX-sh, kein Python, exit 0 immer.

make install-hook
generator plugin.js

Theme-table generator

Liest colors.toml aus /usr/share/omarchy/themes/ (mit --include-user auch aus ~/.config/omarchy/themes/) und schreibt den // BEGIN GENERATED THEMES … // END GENERATED THEMES-Block in desktop/plugin.js neu. HOST=<ssh> liest aus der Ferne.

make generate

In 30 Sekunden drin.

Plugin und Hook sind zwei voneinander unabhängige Pfade. Plugin läuft nach Reload, Hook nach make install-hook. Beide idempotent.

1. Plugin in ~3 s · via Hermes CLI 
hermes plugins install https://github.com/cabroe/omarchy-themes

Anschließend Hermes Desktop neu laden, ⌘K → Reload desktop plugins. In Settings → Capabilities → Plugins → omarchy-themes einmalig aktivieren.

2. Hook idempotent · aus Plugin-Root 
make install-hook

Kopiert hooks/hermes-skin-sync.sh nach ~/.config/omarchy/hooks/theme-set.d/. Re-run jederzeit möglich (überschreibt). Undo mit make uninstall.

Auto-Sync ausschalten: touch ~/.local/state/omarchy/toggles/skip-hermes-theme-changes — Picker und ⌘K bleiben funktional, der Hook triggert nur nicht mehr.
