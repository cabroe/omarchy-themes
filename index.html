Syncs every Omarchy theme to Hermes Desktop

This repo is a Hermes Desktop plugin + an Omarchy hook. One install, theme-switch anywhere — desktop, CLI, TUI, status bar, notifications — all flip together, automatically.

★ omarchy-themes

Desktop plugin

Registers every Omarchy palette as a Hermes-Desktop theme — picker, ⌘K palette, settings card.

hermes plugins install https://github.com/cabroe/omarchy-themes
★ omarchy-theme-set

Omarchy hook

Runs on every omarchy theme set — writes ~/.hermes/skins/<slug>.yaml and activates it (~3 s).

make install-hook
★ themes.json

Generator

Reads colors.toml from system + user dirs and rewrites the plugin's theme table after each Omarchy update.

make generate
