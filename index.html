❯ omarchy · hermes desktop plugin

Omarchy-Themes, Hermes-nativ.

Ein Hermes-Desktop-Plugin, das Omarchy-Themes nach Hermes Desktop synct — inklusive der Themes, die du selbst installiert hast. omarchy theme set nord, und Picker und ⌘K färben sich mit. Der CLI/TUI-Skin folgt, sobald der Hook installiert ist (make install-hook).

In 30 Sekunden drin.

Das Plugin bringt den Desktop-Picker und schaltet ihn bei omarchy theme set automatisch mit.

Terminal ein Befehl · ~3 s 
hermes plugins install https://github.com/cabroe/omarchy-themes
App vier Schritte · ohne Terminal
  1. Settings → Capabilities → Plugins
  2. Von Git installieren
  3. Repository-URL einfügen, Repository prüfen
  4. Installieren — die App schaltet das Plugin direkt ein

Auto-Sync ausschalten: touch ~/.local/state/omarchy/toggles/skip-hermes-theme-changes — Picker und ⌘K bleiben funktional.

Deinstallation ein Befehl · entfernt Plugin und Config-Einträge 
hermes plugins remove omarchy-themes

Ohne Terminal: dieselbe Seite → Papierkorb in der Zeile omarchy-themes → Deinstallieren. Die App löscht den Ordner und entlädt das Plugin sofort — ein Neustart ist dafür nicht nötig.

Reste, die bleiben dürfen: die Skin-Dateien unter ~/.hermes/skins/<slug>.yaml. Hast du den Auto-Sync per Toggle abgeschaltet, liegt zusätzlich ~/.local/state/omarchy/toggles/skip-hermes-theme-changes herum — löschen, wenn du ihn nicht mehr brauchst.

Sync in eine Richtung: Omarchy → Hermes.

omarchy theme set schreibt über den Hook ins Hermes-Skin-File und setzt display.skin in der Hermes-Config. Der Desktop-Picker wählt danach nur noch Themes in Hermes aus; er schreibt nichts nach Omarchy zurück.

  1. [1] Omarchy CLI

    omarchy theme set nord

    Source-of-Truth für Theme-Colors via colors.toml (User > System > current).

  2. [2] omarchy-themes

    hermes skin use nord

    Hook schreibt ~/.hermes/skins/nord.yaml (22 Keys, hex 3- oder 6-stellig), Plugin registriert die Palette im Picker und ⌘K.

  3. [3] Hermes UI

    applyTheme('nord')

    Desktop, CLI, TUI — alles in einem Schritt umgefärbt (light/dark + Accent via Rec.709-Luma-Synth).
